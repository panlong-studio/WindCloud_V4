## 以长短命令分离为目标架构

### 1. 用一个带状态的小火车传输命令，服务端可接收 4 种状态的命令：

- **登录 SIGNAL**：主线程执行
- **注册 REGISTER**：主线程执行
- **短命令**：主线程执行
- **token 验证 TOKEN**：主线程验证，验证通过交给子线程执行

------

### 数据结构定义

```c
// 传输命令用的小火车
typedef struct tain_state_s {
    int length;
    int state;
    int pre_length; // 如果是注册和登录，用于记录用户名长度，如果是命令，用于记录命令部分长度
    char buf[1000];
} train_state_t;
```

------

### 逻辑实现代码（图片 1：Token 验证与任务分发）

```c
case TOKEN:
    // 验证 token 值，成功返回对应客户端在队列中的位置
    ret = token(train_get, netFd); 
    if (ret != -1) // 验证成功，唤醒子线程
    {
        // 把 netFd 从监听中去除，这是客户端的子线程发来的，服务端主线程不再监听
        epollDel(netFd, epfd);
        pthread_mutex_lock(&threadPool.taskQueue.mutex);
        // 把 user_id 和 netFd 传给子线程
        taskEnqueue(&threadPool.taskQueue, ret, netFd); 
        printf("Time to work!\n");
        pthread_cond_signal(&threadPool.taskQueue.cond);
        pthread_mutex_unlock(&threadPool.taskQueue.mutex);
    }
    default:
        break;
}
```

### 逻辑实现代码（图片 2：主线程命令分发）

```c
switch(train_get.state)
{
    case REGISTER:
        register_user(train_get, netFd);
        break;
        
    case LOGIN:
        ret = login(train_get, netFd, &clientQueue);
        if (ret == 0)
        {
            fdAdd(netFd, &clientQueue); // 登录成功开始计时
        }
        // clientQueue.time_out[netFd] = 5; // 登录成功后也需要重置等待时间
        break;

    case LS:
    case CD:
    case PWD:
    case REMOVE:
    case MKDIR:
        // 收到客户端发来的命令，对应的等待时间重置为 300s (图中注释为 300，文字描述为 5)
        clientQueue.time_out[netFd] = 300; 
        handle_short_cmd(train_get, netFd, clientQueue.client[netFd]);
        break;

    case PUTS:
    case GETS:
        clientQueue.time_out[netFd] = 300;
        break;
}
```
